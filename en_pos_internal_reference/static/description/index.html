Frequently Asked Questions

Everything you need to know about Odoo App Store index generation and compatibility

Is the generated HTML 100% compliant with Odoo App Store rules?
Yes! All exported code uses standard Bootstrap grid classes and inline styles with zero external scripts or forbidden tags, ensuring 100% compliance with Odoo App Store sanitization guidelines.
Where should I place the generated index.html in my module?
Save the downloaded file as index.html inside your Odoo module under the static/description/ folder (e.g. your_module/static/description/index.html).
Can I customize the color palette and typography?
Yes! You can choose from pre-set curated palettes (Odoo Purple, Ocean Blue, Emerald, etc.) or set custom primary and accent hex colors for each individual widget.
Does this module work on both Community and Enterprise?
Yes, Index File Maker runs smoothly on both Odoo Community and Enterprise editions across Odoo 17, 18, 19, and 20.
